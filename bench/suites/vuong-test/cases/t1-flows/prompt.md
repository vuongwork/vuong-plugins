Test màn L01 (Đăng ký nghỉ phép) của project này: FE (`public/`, `lib/`) và API (`server.js`). Spec nằm trong `docs/spec/`.

Lần này chỉ làm phần phân tích, chưa viết test case và chưa viết test:
1. Nguồn spec đã dùng → `test-work/L01/spec-sources.md`
2. Toàn bộ flow của màn và API (chế độ, nút, nhánh, validation, mã lỗi, side effect), mỗi dòng có `file:line` và có nằm trong spec hay không → `test-work/L01/flows.md` (bảng markdown)
3. Mọi chỗ spec và code khác nhau (giá trị, giới hạn, message, điều kiện hiện nút, quyền...), mỗi khác biệt một dòng, ghi spec nói gì (trích file + ô) và code làm gì (`file:line`) → `test-work/L01/diff.md` (bảng markdown)

Dừng khi đã có 3 file đó.
